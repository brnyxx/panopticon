# Security Policy

## Reporting a vulnerability in Panopticon
Email security@<domain> or open a private security advisory on GitHub. We acknowledge within 3 business days.

## Reporting a finding *about an MCP server* observed with Panopticon
Panopticon reports facts about what a server did. If you believe an observation is wrong, open an issue with the observation JSON and the reproduction command. If you are the server's maintainer, add a `.panopticon.yaml` self-declaration (docs/self-declaration.md) so future observations compare against it.

Project publications about third-party servers follow docs/disclosure.md.
