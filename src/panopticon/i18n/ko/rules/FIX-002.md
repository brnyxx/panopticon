# FIX-002 — 결정적인 정확한 버전 고정

## 문제
패키지 명세에 `@latest`처럼 정확한 버전이 없거나 버전 태그가 없습니다. 발견 결과는 정확한 설정 포인터의 패키지 값을 식별합니다.

## 영향
시간이 지나면 의존성 해결기가 서로 다른 릴리스를 선택하여 설치 코드와 관찰된 동작이 달라질 수 있습니다. 반복 가능한 설치나 검토 가능한 업데이트가 필요할 때 문제가 됩니다.

## 근거
CFG-002는 패키지 명세와 설정 포인터를 기록하며, 관찰하지 않은 패키지의 동작을 추론하지 않습니다.

## 권장 조치
`pano fix`를 실행하고 FIX-002를 선택한 다음 해결된 정확한 버전을 입력하십시오. 패키지 이름은 유지하고 `1.2.3`과 같은 시맨틱 버전(선택적으로 사전 출시 또는 빌드 접미사 포함)이나 커밋 해시를 사용해 바꿉니다.

## 확인 방법
`pano doctor`를 실행하여 CFG-002가 사라졌는지 확인하십시오. 같은 설정으로 설치를 다시 실행하고 기록된 포인터의 패키지 명세가 변경되지 않았으며 선택한 정확한 버전을 포함하는지 확인하십시오.

## 제한
정확한 고정만으로 패키지가 신뢰할 수 있거나 취약점이 없거나 의도한 출처에서 제공된다고 증명할 수 없습니다. 커밋 해시는 출처가 일관되게 해석할 때에만 콘텐츠를 식별합니다. 지원되지 않는 패키지 형식이나 불완전한 관찰 결과는 `UNKNOWN`으로 남습니다.
