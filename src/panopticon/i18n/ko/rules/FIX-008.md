# FIX-008 — 프로토콜 검증 HTTP-HTTPS 교체

## 문제
원격 MCP 항목이 평문 `http` URL을 사용합니다. FIX-008은 프로토콜 검사를 통과한 경우에만 해당 URL을 `https` 형식으로 바꿀 수 있습니다.

## 영향
평문 HTTP로 전송한 요청은 네트워크 중개자가 관찰하거나 변경할 수 있습니다. 원격 엔드포인트와 클라이언트가 동등한 전송 보호를 제공하지 않는 네트워크에서 통신할 때 문제가 됩니다.

## 근거
CFG-008은 URL 값과 정확한 설정 포인터를 기록합니다. 교체를 계획하기 전에 Panopticon은 HTTPS 후보로 제한된 `POST` MCP `initialize` 요청을 보냅니다. 검사가 통과하려면 2xx 응답에 JSON-RPC `2.0`, `id` `1`, 문자열인 `result.protocolVersion`이 있어야 합니다.

## 권장 조치
`pano fix --rule FIX-008`을 실행하고 제안된 URL 차이를 검토한 뒤 적용하십시오. `HEAD` 응답, 일반적인 HTTP 성공, 리디렉션 또는 필요한 MCP 필드가 없는 응답만으로는 충분하지 않으므로 검사를 통과하지 못하면 안내만 제공됩니다. 저널 ID를 보관하고 필요하면 `pano fix --undo <20-hex-journal-id>`로 정확히 되돌리십시오.

## 확인 방법
`pano doctor`를 실행하여 편집한 포인터의 CFG-008이 더 이상 없고 URL이 `https`인지 확인하십시오. 되돌리려면 `pano fix --undo <20-hex-journal-id>`를 실행하고 설정의 SHA-256 해시를 변경 전 해시와 비교하십시오.

## 제한
이 변경은 제한된 initialize 응답을 넘어 엔드포인트 신원, 애플리케이션 권한, 가용성 또는 안전성을 증명하지 않습니다. 모든 경로나 요청을 검증하지 않으며, 자격 증명이 포함된 URL이나 자격 증명 쿼리 키가 있는 URL은 다루지 않습니다.
