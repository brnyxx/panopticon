# FIX-004 — 파일시스템 경로 좁히기

## 문제
파일시스템 MCP 서버 설정이 `~`, `/`, `$HOME` 또는 드라이브 루트와 같은 광범위한 경로를 허용합니다. 이 발견은 해당 경로가 있는 정확한 설정 포인터를 식별합니다.

## 영향
서버가 작업에 필요한 범위를 넘어 파일시스템을 읽거나 쓸 수 있습니다. 서버가 활성화되어 있고 프로세스 권한에 의도한 프로젝트나 작업공간 밖의 파일이 포함될 때 문제가 됩니다.

## 근거
CFG-004에는 서버 항목, 파일시스템 경로 값 및 정확한 설정 포인터가 기록됩니다. 관찰에는 파일 내용이 포함되지 않으며 설정된 경로를 넘어선 접근을 추론하지 않습니다.

## 권장 조치
`pano fix`를 실행하고 FIX-004를 선택합니다. 홈, 루트 또는 상위 디렉터리 탐색 경로가 아닌 작업에 적합한 더 좁은 기존 디렉터리를 입력합니다. 선택한 경로는 정규화되어 기록된 포인터에서 대체되며, 프롬프트를 거부하면 설정은 변경되지 않습니다.

## 확인 방법
`pano doctor`를 실행하여 해당 항목에서 CFG-004가 사라졌는지 확인합니다. 기록된 포인터를 검사하여 루트 또는 홈 전체 값이 아닌 선택한 더 좁은 경로가 들어 있는지 확인합니다.

## 제한
이 규칙은 서버가 파일에 접근했는지, 선택한 디렉터리가 존재하는지 또는 프로세스 권한이 그 범위로 제한되는지를 입증하지 않습니다. 관찰된 항목 밖의 다른 설정 사본이나 경로는 검사하지 않습니다. 지원되지 않거나 관찰이 불완전한 경우는 `UNKNOWN`으로 남습니다.
