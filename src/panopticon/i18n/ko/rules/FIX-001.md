# FIX-001 — 안전한 자격 증명 참조

## 문제
설정 값이 자격 증명 형태의 환경 변수 값이나 원격 헤더로 식별되었거나, 엔트로피가 높은 환경 변수 값으로 식별되었습니다. 정확한 설정 포인터로 값을 선택하며 자격 증명 자체는 기록하지 않습니다.

## 영향
값을 설정에 그대로 두면 설정을 읽는 주체나 백업에 자격 증명이 노출될 수 있습니다. 값이 실제로 사용 중이거나 서비스 접근 권한을 부여할 때 이 위험이 발생합니다.

## 근거
관련 CFG-001, CFG-007 또는 CFG-011 발견 결과는 자격 증명 값을 저장하지 않고 설정 포인터, 환경 변수 키 또는 헤더 이름, 분류만 기록합니다.

## 권장 조치
`pano fix`를 실행하고 FIX-001을 선택하십시오. 완전한 OS 자격 증명 저장소 백엔드가 있으면 값을 그곳에 저장하고 `${KEY}` 참조로 바꿉니다. 환경 변수 참조를 지원하지 않는 클라이언트는 `SecretStore`에서 읽은 값을 wrap 실행 시 메모리로 주입하고 `pano install`을 고려하십시오. 보안 백엔드를 사용할 수 없거나 선택을 거부하면 결과는 안내만 제공하며 자격 증명이 포함된 파일은 쓰지 않습니다.

## 확인 방법
`pano doctor`를 실행하여 해당 설치에서 관련 CFG-001, CFG-007 또는 CFG-011 발견 결과가 사라졌는지 확인하십시오. 설정에 자격 증명 값 대신 `${KEY}`가 있고 평문 환경 변수 파일이 생성되지 않았는지 확인하십시오.

## 제한
이 규칙만으로 자격 증명이 유효하거나 활성 상태인지, 폐기되었는지 증명할 수 없으며 관찰한 설정 밖의 모든 사본이 삭제되었다고도 할 수 없습니다. 지원되지 않거나 불완전한 관찰 결과는 `UNKNOWN`으로 남습니다. 자동 변경에는 자격 증명 저장소 기능이 필요하며 안내만 제공된 결과는 비밀 값을 수정하지 않습니다.
