# FIX-010 — 선택한 비활성 항목 제거

## 문제
클라이언트 설정에 비활성으로 표시된 MCP 서버 항목이 있습니다. FIX-010은 선택한 항목을 설정 문서에서 제거합니다.

## 영향
비활성 항목은 비활성으로 표시되어도 저장된 인벤토리에 남습니다. 항목을 제거하면 설정 인벤토리가 바뀌며 해당 문서를 검사하는 도구나 작업 흐름에 영향을 줄 수 있습니다.

## 근거
CFG-009는 비활성 항목 분류와 선택한 서버 항목의 정확한 JSON 설정 포인터를 기록합니다.

## 권장 조치
`pano fix --rule FIX-010`을 실행하고 기록된 항목을 선택한 다음 차이를 검토하여 제거를 적용하십시오. 저널 ID를 보관하고 원래 항목이 필요하면 `pano fix --undo <20-hex-journal-id>`로 정확히 되돌리십시오.

## 확인 방법
`pano doctor`를 실행하여 선택한 CFG-009 항목이 해당 포인터에 더 이상 없는지 확인하십시오. 되돌리려면 `pano fix --undo <20-hex-journal-id>`를 실행하고 설정의 SHA-256 해시를 변경 전 해시와 비교하십시오.

## 제한
제거만으로 클라이언트 프로세스가 중지되었거나 다른 설정에 같은 항목이 없거나 서버를 신뢰할 수 있거나 연결 가능하다는 것을 증명하지 않습니다. 선택한 설정 항목만 변경하며 런타임 동작을 추론하지 않습니다.
