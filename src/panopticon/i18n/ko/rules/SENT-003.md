# SENT-003 — 도구 입력 검증 누락

## 문제
Python MCP 도구 핸들러가 프레임워크 검증이나 명시적 검증 전에 타입이 없거나 지나치게 넓은 타입의 매개변수를 사용합니다. 정적 규칙은 키워드 인자, 타입 주석이 없는 매개변수, `Any` 또는 `dict`로 주석된 매개변수, 그리고 먼저 인식된 검증이 수행되지 않은 디스패처의 `arguments` 또는 `kwargs` 사용을 표시합니다.

## 영향
첫 사용 전에 인식 가능한 검증 단계가 없으면 분석된 경로에서 도구 입력의 형태와 타입이 확인되지 않은 채 처리될 수 있습니다. 실제 영향은 런타임에서 해당 값이 사용되는 방식에 따라 달라집니다.

## 근거
AST 규칙 `sentinel.sent003.missing-input-validation`은 Python MCP 도구 영역을 검사합니다. 구체적인 타입 주석은 타입이 지정된 것으로 처리하고, `model_validate`, `parse_obj`, `validate`, `jsonschema.validate` 호출을 검증으로 인식하며, 검증되지 않은 매개변수 또는 디스패처 인자 사용의 최초 위치를 기록합니다. 결과에는 일치한 매개변수 또는 사용 위치가 표시됩니다.

## 권장 조치
각 도구 매개변수를 처음 사용하기 전에 구체적인 핸들러 타입, Pydantic 모델 또는 JSON Schema로 검증하세요. 디스패처 인자를 조회하거나 인덱싱하기 전에 검증하세요.

## 확인 방법
`pano scan <path>`를 다시 실행하세요. 검사된 모든 도구 매개변수가 구체적으로 타입 지정되었거나 최초 사용 전에 인식된 검증 호출을 거치고, 디스패처 인자가 접근 전에 검증되면 SENT-003 결과가 없어야 합니다.

## 제한
이는 정적 AST 근거이며 도구 호출을 관찰한 결과나 잘못된 입력이 허용되었다는 증명이 아닙니다. 구성된 Python MCP 패턴과 인식된 검증 호출만 다루므로 별칭, 사용자 정의 검증기, 암시적 프레임워크 동작, 동적 디스패치, 검사하지 않은 파일, 분석 영역 밖의 사용은 반영되지 않을 수 있습니다.
