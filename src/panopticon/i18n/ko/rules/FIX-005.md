# FIX-005 — 중복 서버 버전 통일

## 문제
동일한 서버 식별자가 서로 다른 패키지 버전으로 두 번 이상 설치되어 있습니다. CFG-005는 중복 항목과 각 정확한 설정 포인터의 패키지 값을 식별합니다.

## 영향
어떤 항목이 선택되는지에 따라 동일한 서버 식별자에 서로 다른 코드가 실행될 수 있습니다. 중복 항목 전체에서 동작을 일관되게 하고 업데이트를 반복 가능하게 해야 할 때 문제가 됩니다.

## 근거
CFG-005에는 서버 식별자, 관찰된 각 패키지 사양과 버전, 해당 설정 포인터가 기록됩니다. 버전 문자열만으로 패키지 동작을 추론하지 않습니다.

## 권장 조치
`pano fix`를 실행하고 FIX-005를 선택합니다. 하나의 정확한 버전을 정하여 나열된 중복 항목에 적용하고, 각 패키지 이름은 유지한 채 버전만 대체합니다. 프롬프트를 거부하면 해당 항목은 변경되지 않습니다.

## 확인 방법
`pano doctor`를 실행하여 해당 서버 식별자에서 CFG-005가 사라졌는지 확인합니다. 나열된 모든 패키지 포인터를 검사하여 동일하게 선택한 정확한 버전을 사용하는지 확인합니다.

## 제한
버전이 같아도 패키지가 신뢰할 수 있거나 출처 간에 동등하거나 취약점이 없음을 입증하지 않습니다. 어느 중복 항목이 실행 시 사용되는지 입증하지 않으며 중복 설치 자체를 삭제하지도 않습니다. 지원되지 않는 패키지 형식이나 관찰이 불완전한 경우는 `UNKNOWN`으로 남습니다.
