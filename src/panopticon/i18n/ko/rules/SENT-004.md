# SENT-004 — 프롬프트 내 도구 콘텐츠 무삭제 사용

## 문제
도구가 제어하는 텍스트가 구성된 신뢰할 수 있는 새니타이저를 거치지 않고 이후 모델 프롬프트로 전달됩니다. 정적 규칙은 도구 출력 또는 도구 설명에서 파생된 값이 OpenAI Responses나 Chat Completions 호출, 또는 인식된 프롬프트 작성 함수의 반환값에서 사용되는 흐름을 보고합니다.

## 영향
신뢰할 수 없는 도구 콘텐츠가 모델에 전달되는 지시나 메시지에 영향을 줄 수 있습니다. 이로 인해 프롬프트 문맥이 바뀌거나 모델이 도구 콘텐츠를 지시로 취급할 수 있으며, 실제 효과는 도달 가능한 흐름과 모델 연동 방식에 따라 달라집니다.

## 근거
AST 규칙 `sentinel.sent004.unsanitized-tool-content`는 `.text`, `.description`, `.content` 속성과 `call_tool`, `list_tools` 호출에서 파생된 값을 표시합니다. 할당을 통해 값을 전파하고 구성된 새니타이저 이름을 인식하며, 새니타이저를 거치지 않은 데이터가 `input`, `instructions`, `messages` 인자로 `responses.create` 또는 `chat.completions.create`에 도달하거나 인식된 프롬프트 함수의 반환값에 도달하면 `prompt-taint` 결과를 기록합니다.

## 권장 조치
모델 프롬프트 콘텐츠를 구성하거나 반환하기 전에 도구 제어 텍스트를 구성된 신뢰할 수 있는 새니타이저로 통과시키세요. 검사 대상 코드가 사용하는 구현에 맞게 새니타이저 구성을 유지하세요.

## 확인 방법
`pano scan <path>`를 다시 실행하세요. 분석된 각 프롬프트 싱크에 도달하는 도구 파생 텍스트가 먼저 구성된 새니타이저를 거치면 SENT-004 결과가 없어야 합니다.

## 제한
이는 정적 함수 내부 AST 근거이며 모델 실행을 관찰한 결과나 프롬프트 인젝션이 발생했다는 증명이 아닙니다. 인식된 Python 소스·할당·새니타이저 구성·프롬프트 싱크·프롬프트 함수만 다루므로 함수 간 흐름, 해석할 수 없는 별칭, 다른 모델 API, 동적 값, 검사하지 않은 파일은 감지되지 않을 수 있습니다.
