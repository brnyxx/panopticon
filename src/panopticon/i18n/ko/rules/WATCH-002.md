# WATCH-002 — 선언 밖 미끼 파일 읽기

## 문제
tool이 선언한 경로 범위 밖의 자격증명 미끼 파일을 읽었습니다.

## 영향
관찰된 읽기가 해당 tool에 귀속된 범위를 벗어납니다.

## 근거
파일 읽기 이벤트에 경로, span, tool, 선언 일치 결과가 기록됩니다.

## 권장 조치
불필요한 읽기를 제거하거나 해당 tool의 정확한 경로와 목적을 선언하세요.

## 확인 방법
`pano watch <name>`을 실행해 읽기가 제거되었거나 권위 있는 범위와 일치하는지 확인하세요.

## 제한
파일 추적이 불완전하면 `UNKNOWN`입니다. open 또는 stat만으로 읽기를 확정하지 않습니다.
