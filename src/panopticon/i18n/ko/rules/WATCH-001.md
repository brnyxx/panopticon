# WATCH-001 — 미끼 값 유출

## 문제
sandbox에 심어둔 미끼 비밀값(파일 또는 환경변수의 가짜 토큰)이 tool 호출 중 외부 트래픽, 파일 쓰기, 프로세스 인자, stderr 중 하나에서 발견되었습니다.

## 영향
이 서버는 작업에 주어지지 않은 자격증명을 읽어 어딘가로 보냈습니다. 미끼에 대해 그렇게 했다면 실제 자격증명에 대해서도 그렇게 합니다.

## 근거
`spans[*].events[kind=leak]`의 `decoy_key`와 `sink`(host:port 또는 경로).

## 권장 조치
maintainer의 설명이 있을 때까지 클라이언트 config에서 이 서버를 제거하세요. 계속 써야 한다면 `pano wrap`을 통해서만 실행하고 `env`에 실제 토큰을 넣지 마세요.

## 확인 방법
`pano watch <name>`을 다시 실행해 모든 span에서 `leak` 이벤트가 없어야 합니다.

## 제한
TLS 페이로드는 검사하지 않습니다. 선언된 host로 TLS를 통해 나가는 유출은 이 규칙으로 탐지되지 않습니다(선언 밖 host는 WATCH-003 참고).
