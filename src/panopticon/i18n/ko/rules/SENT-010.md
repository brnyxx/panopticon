# SENT-010 — 인젝션 페이로드 실행

## 문제
동적 프로브 중 도구 인자가 Sentinel 스크래치 카나리 부작용을 일으킵니다. 이 규칙은 도구 데이터로 제공된 인젝션 문자열이 실행되는지를 식별합니다.

## 영향
인자 텍스트가 코드나 명령으로 해석되면 공격자가 도구 권한으로 의도하지 않은 동작을 유발할 수 있습니다. 카나리 관찰은 프로브의 로컬 스크래치 경로에만 해당하며 다른 환경의 영향을 입증하지 않습니다.

## 근거
프로버는 스키마와 호환되는 문자열 필드를 선택하고 정확한 표식 `__SENTINEL_INJECTION__`을 제출합니다. 실행 시 이 표식은 격리된 Sentinel 카나리 경로를 touch하는 페이로드로 대체됩니다. 호출 후 카나리 파일이 존재할 때만 SENT-010 근거가 생성됩니다. 응답과 로그는 삭제 처리되며 응답 근거는 UTF-8 기준 16,384바이트로 제한됩니다.

## 권장 조치
도구 인자를 무해한 데이터로 취급하세요. 동적 평가와 명령 문자열 조합을 제거하고 매개변수화된 API를 사용하며, 핸들러 실행 전에 엄격한 스키마 검증을 적용하세요. 프로브 카나리는 운영 상태와 격리하세요.

## 확인 방법
격리된 Docker 프로브 환경에서 동적 스캔을 실행하고 제한된 동적 근거를 확인하세요. 표식이 데이터로 남고 스크래치 카나리가 생성되지 않으면 SENT-010 근거가 생성되지 않아야 합니다.

## 제한
이는 한 번의 제한된 카나리 관찰이며 모든 인젝션 변형이 차단되거나 다른 곳에서 임의 코드가 실행되지 않았다는 증명이 아닙니다. 승인된 각 프로브는 새 세션에서 한 번 실행되고, 스키마 호환 필드·무해한 기본 인자·삭제된 로그를 사용하며, 프로브당 20초와 캠페인 전체 120초의 시간 제한을 적용합니다. 로컬 카나리 부작용만 확인하므로 다른 싱크·도구·전송 방식·별칭·동시성 및 검사하지 않은 코드는 대상이 아니며 전체 보안 판정은 아닙니다.
