# WATCH-004 — idle 구간 네트워크 활동

## 문제
tool 호출 사이의 예약된 idle span에서 네트워크 활동이 발생했습니다.

## 영향
활성 tool 호출에 귀속되지 않은 통신이 관찰되었습니다.

## 근거
네트워크 근거가 `__idle__` 반개방 span에 귀속됩니다.

## 권장 조치
백그라운드 통신을 끄거나 필요한 endpoint를 문서화하고 격리하세요.

## 확인 방법
idle 구간을 다시 관찰해 네트워크 이벤트가 귀속되지 않는지 확인하세요.

## 제한
span 또는 네트워크 coverage가 불완전하면 `UNKNOWN`입니다.
