# SENT-008 — 범위 밖 도구 실행

## 문제
서버가 선언된 권한 매니페스트에 없는 도구를 실행합니다. SENT-008은 권한이 부여되지 않은 도구 호출이 기능 경계에서 거부되는지 확인하는 제한된 런타임 프로브입니다.

## 영향
권한이 부여되지 않은 도구를 실행하면 매니페스트가 허용하지 않은 작업에 접근하여 의도한 기능 정책을 우회할 수 있습니다. 프로브 결과는 격리된 단일 호출을 설명할 뿐 다른 실행의 범위나 결과를 입증하지 않습니다.

## 근거
고정된 동적 카탈로그는 SENT-008을 “범위 밖 도구 실행”으로 정의하며, 선언된 권한 매니페스트에서 제외된 도구를 서버가 실행한 경우를 뜻합니다. 프로버는 필요한 권한 매니페스트를 로드하고 새 세션에서 도구를 나열한 다음 `manifest.tools`에 없는 도구 중 이름순으로 첫 번째를 선택합니다. 그런 도구가 없으면 대체 이름 `__sentinel_out_of_scope__`을 호출합니다. 오류가 아닌 응답(`isError`가 거짓)이면 SENT-008 근거를 기록합니다. 요청·제한된 응답·삭제된 로그가 동적 근거로 보존됩니다.

## 권장 조치
핸들러를 호출하기 전에 활성 기능 정책에서 허용하지 않은 도구 호출을 거부하세요. 모든 전송 및 디스패치 경로에 동일한 매니페스트 검사를 적용하고 허용되지 않은 이름에는 프로토콜 수준 오류를 반환하세요.

## 확인 방법
격리된 Docker 프로브 환경에서 동적 스캔을 실행하세요. 선택된 허용되지 않은 이름(또는 대체 이름)이 핸들러 실행 전에 오류로 거부되면 SENT-008 근거가 생성되지 않아야 합니다. 매니페스트가 허용한 도구의 일반 호출이 계속 동작하는지도 확인하세요.

## 제한
이는 제한된 런타임 근거이며 모든 매니페스트 외 이름·전송·세션·배포·디스패치 경로를 보장하지 않습니다. 캠페인은 새 세션에서 승인된 프로브를 한 번만 수행하며, 광고된 도구 중 이름순으로 첫 번째 허용되지 않은 도구만 검사하거나 그런 도구가 없으면 대체 이름을 사용합니다. 광고되지 않은 도구, 다른 별칭, 동시 호출, 전송 오류, 검사하지 않은 코드는 다루지 않으며 핸들러 부작용도 입증하지 않습니다. 프로브의 성공 또는 실패만으로 서비스 전체의 안전성에 대한 결론을 내릴 수 없습니다.
