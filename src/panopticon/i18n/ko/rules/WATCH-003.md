# WATCH-003 — 선언 밖 host 연결

## 문제
tool이 권위 있게 선언한 host 범위 밖으로 연결했습니다.

## 영향
서버가 해당 tool에 귀속되지 않은 목적지와 통신했습니다.

## 근거
connect, DNS 또는 클라이언트에서 보이는 요청 근거에 정규화된 host와 span이 기록됩니다.

## 권장 조치
연결을 제거하거나 해당 tool의 정확한 목적지와 이유를 선언하세요.

## 확인 방법
호출을 반복하고 관찰된 모든 host를 권위 있는 선언과 비교하세요.

## 제한
allowlist 인프라는 제외 근거로 남습니다. 선언이 불완전하면 `UNKNOWN`입니다.
