# CFG-010 — System path argument

## Problem
An argument names an absolute path under a system directory.

## Impact
The server may read configuration or state outside the decoy project.

## Evidence
The finding records the system-path classification, not file contents.

## Recommended action
Remove the argument or replace it with a task-specific path.

## How to verify
Run `pano doctor` and confirm CFG-010 is absent.

## Limits
The rule does not prove that the path was accessed.
