# CFG-009 — Disabled server entry

## Problem
The client configuration contains a disabled MCP entry.

## Impact
Inventory expectations can differ from what the client launches.

## Evidence
The finding records the disabled-entry classification.

## Recommended action
Enable the entry or remove it through the supported config workflow.

## How to verify
Run `pano doctor` and confirm the intended entry state.

## Limits
Disabled entries are reported as inventory information.
