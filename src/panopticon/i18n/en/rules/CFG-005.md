# CFG-005 — Installation version mismatch

## Problem
The same server identity is installed with different resolved versions.

## Impact
Clients can exhibit different behavior for the same server name.

## Evidence
The finding records the shared server identity and mismatch classification.

## Recommended action
Choose one version with `pano fix`.

## How to verify
Run `pano doctor` and confirm CFG-005 is absent.

## Limits
Low-confidence local identities are not merged by this rule.
