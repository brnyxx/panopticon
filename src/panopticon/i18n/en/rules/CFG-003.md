# CFG-003 — Shell evaluation command

## Problem
The configured command contains a shell or evaluation form.

## Impact
Quoting and expansion can execute more than the visible package command.

## Evidence
The finding records the matched command classification.

## Recommended action
Use a direct executable and argument list.

## How to verify
Run `pano doctor` and confirm CFG-003 is absent.

## Limits
This rule does not infer the expanded command.
