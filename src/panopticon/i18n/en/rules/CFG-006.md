# CFG-006 — Unverifiable package source

## Problem
The installation source cannot be verified in a supported registry.

## Impact
Registry history and package identity coverage remain incomplete.

## Evidence
The finding records the normalized source classification.

## Recommended action
Use a registry package or review the local source directly.

## How to verify
Run `pano doctor` and inspect the source and history states.

## Limits
An unverifiable source is not a behavioral verdict.
