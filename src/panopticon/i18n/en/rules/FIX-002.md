# FIX-002 — Deterministic exact version pin

## Problem
A package specification does not contain an exact version, such as `@latest` or no version tag. The finding identifies the package value at an exact configuration pointer.

## Impact
Dependency resolution can select different releases over time, changing the installed code and its observed behavior. This matters when repeatable installations or reviewable updates are required.

## Evidence
CFG-002 records the package specification and its configuration pointer; it does not infer behavior from a package that was not observed.

## Recommended action
Run `pano fix` and select FIX-002, then provide the resolved exact version. The replacement keeps the package name and uses a semantic version such as `1.2.3` (optionally with a prerelease or build suffix) or a commit hash.

## How to verify
Run `pano doctor` and confirm CFG-002 is absent. Re-run the installation with the same configuration and confirm the package specification at the recorded pointer is unchanged and contains the selected exact version.

## Limits
An exact pin does not prove that the package is trustworthy, vulnerability-free, or available from the intended source. A commit hash identifies content only when the source resolves it consistently. Unsupported package formats or incomplete observation remain `UNKNOWN`.
