# FIX-010 — Remove a selected disabled entry

## Problem
A client configuration contains an MCP server entry marked disabled. FIX-010 removes the selected entry from the configuration document.

## Impact
The disabled entry remains part of the stored inventory even though it is marked inactive. Removing it changes the configuration inventory and can affect tools or workflows that inspect that document.

## Evidence
CFG-009 records the disabled-entry classification and the exact JSON configuration pointer of the selected server entry.

## Recommended action
Run `pano fix --rule FIX-010`, select the recorded entry, review the diff, and apply the removal. Keep the journal ID and undo exactly with `pano fix --undo <20-hex-journal-id>` if the original entry is required.

## How to verify
Run `pano doctor` and check that the selected CFG-009 entry is no longer present at its pointer. To undo, run `pano fix --undo <20-hex-journal-id>` and compare the configuration's SHA-256 hash with the pre-change hash.

## Limits
Removal does not prove that a client process stopped, that another configuration lacks the same entry, or that the server is trustworthy or reachable. It changes only the selected configuration entry and does not infer runtime behavior.
