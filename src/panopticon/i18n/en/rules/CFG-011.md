# CFG-011 — Token-shaped remote header

## Problem
A remote MCP header contains a token-shaped value.

## Impact
The credential is sent with remote MCP requests.

## Evidence
The finding records the header key and classification, never the value.

## Recommended action
Move the value to the credential store with `pano fix`.

## How to verify
Run `pano doctor` and confirm CFG-011 is absent.

## Limits
Pattern matching does not prove the token is active.
