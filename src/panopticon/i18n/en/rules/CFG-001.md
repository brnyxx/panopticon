# CFG-001 — Token-shaped environment value

## Problem
An environment value matches a known credential token pattern.

## Impact
The configured process can receive that credential when it starts.

## Evidence
The finding records the environment key and token classification, never the value.

## Recommended action
Move the value to the credential store with `pano fix`.

## How to verify
Run `pano doctor` and confirm CFG-001 is absent for the installation.

## Limits
Pattern matching does not prove the value is active.
