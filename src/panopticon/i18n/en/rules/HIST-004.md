# HIST-004 — Archived or inactive repository

## Problem
The repository is archived or has no observed release activity for twelve calendar months.

## Impact
Maintenance and response coverage may be reduced.

## Evidence
The finding records the archive or inactivity classification.

## Recommended action
Review repository status and available alternatives.

## How to verify
Refresh repository history and run `pano doctor`.

## Limits
Missing activity data is reported as unknown, not as a finding.
