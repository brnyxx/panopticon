# CFG-008 — Plaintext remote endpoint

## Problem
The remote MCP endpoint uses HTTP without transport encryption.

## Impact
Requests and responses can be observed or modified on the network path.

## Evidence
The finding records the endpoint transport classification without its query.

## Recommended action
Change the endpoint to HTTPS with `pano fix` after verification.

## How to verify
Run `pano doctor` and confirm CFG-008 is absent.

## Limits
HTTPS does not describe what the remote server does.
