# FIX-004 — Narrow filesystem path

## Problem
A filesystem MCP server configuration grants a broad path such as `~`, `/`, `$HOME`, or a drive root. The finding identifies the exact configuration pointer containing that path.

## Impact
The server may be able to read or write across more of the filesystem than the task requires. This matters when the server is active and its process permissions include files outside the intended project or workspace.

## Evidence
CFG-004 records the server entry, filesystem path value, and exact configuration pointer. The observation does not include file contents or infer access beyond the configured path.

## Recommended action
Run `pano fix` and select FIX-004. Provide a narrower existing directory appropriate for the task, rather than a home, root, or parent-traversal path. The selected path is normalized and replaced at the recorded pointer; declining the prompt leaves the configuration unchanged.

## How to verify
Run `pano doctor` and confirm CFG-004 is absent for the entry. Inspect the recorded pointer and confirm it contains the selected narrower path, with no root or home-wide value.

## Limits
This rule does not prove that the server accessed any file, that the selected directory exists, or that process permissions are restricted to it. It does not inspect other configuration copies or paths outside the observed entry. Unsupported or incomplete observation remains `UNKNOWN`.
