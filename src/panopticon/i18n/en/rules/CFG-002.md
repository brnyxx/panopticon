# CFG-002 — Unpinned package version

## Problem
The package command has no fixed version or requests `latest`.

## Impact
A later launch can execute different package contents without a config change.

## Evidence
The finding records the normalized package classification.

## Recommended action
Resolve and pin a version with `pano fix`.

## How to verify
Run `pano doctor` and confirm CFG-002 is absent.

## Limits
A pin does not describe the package's runtime behavior.
