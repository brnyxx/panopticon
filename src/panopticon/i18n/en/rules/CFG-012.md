# CFG-012 — Stdio server not wrapped

## Problem
A stdio MCP installation is not routed through Panopticon's wrapper.

## Impact
Continuous transport records are not collected for that installation.

## Evidence
The finding records the transport and wrapper state.

## Recommended action
Run `pano install` for the client.

## How to verify
Run `pano doctor` and confirm CFG-012 is absent.

## Limits
This is a coverage notice, not a behavioral verdict.
