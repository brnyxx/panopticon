# CFG-004 — Broad filesystem grant

## Problem
A filesystem-class server is granted a home, root, or drive-root path.

## Impact
The server can reach files unrelated to its stated task.

## Evidence
The finding records only the broad-path classification.

## Recommended action
Narrow the path with `pano fix`.

## How to verify
Run `pano doctor` and confirm CFG-004 is absent.

## Limits
The rule applies only when the server is classified as filesystem-capable.
