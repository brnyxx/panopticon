# FIX-005 — Unify duplicate server versions

## Problem
The same server identifier is installed more than once with different package versions. CFG-005 identifies the duplicate entries and the package value at each exact configuration pointer.

## Impact
Different installations can run different code for the same server identifier, depending on which entry is selected. This matters when consistent behavior and repeatable updates are required across the duplicate entries.

## Evidence
CFG-005 records the server identifier, each observed package specification, its version, and the corresponding configuration pointer. It does not infer package behavior from the version strings.

## Recommended action
Run `pano fix` and select FIX-005. Choose one exact version and apply it to the listed duplicate entries, preserving each package name while replacing only its version. Declining a prompt leaves that entry unchanged.

## How to verify
Run `pano doctor` and confirm CFG-005 is absent for the server identifier. Inspect every listed package pointer and confirm that each uses the same selected exact version.

## Limits
Matching versions do not prove that the packages are trustworthy, equivalent across sources, or free of vulnerabilities. The rule does not prove which duplicate entry is used at runtime or remove duplicate installations. Unsupported package formats or incomplete observation remain `UNKNOWN`.
