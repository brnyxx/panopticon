# CFG-007 — High-entropy environment value

## Problem
An environment value crosses the frozen length and entropy thresholds.

## Impact
The value may be credential material exposed to the server process.

## Evidence
The finding records the key and entropy classification, never the value.

## Recommended action
Move the value to the credential store with `pano fix`.

## How to verify
Run `pano doctor` and confirm CFG-007 is absent.

## Limits
Entropy is a review signal and does not identify the value's purpose.
